# App Android

Tessel sur Android avec Expo : une vraie app native qui partage le cœur Rust avec le web.

## Périmètre

- App Expo (même version que `liste_course`), module natif `tessel-core`, base locale chiffrée.
- Mêmes écrans que le web, avec caméra, galerie et notifications FCM.
- Distribution aux proches.

## Terminé quand

- Le parcours de la première étape réussie se fait entièrement sur Android.
- Les proches installent l'app sans passer par une procédure technique.

## Dépendances

- Epics 02 à 11, selon les écrans.
