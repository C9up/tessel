# Modération par l'opérateur

Permettre à l'opérateur d'agir sur les abus signalés sans jamais lire ce qu'on ne lui montre pas.

## Périmètre

- Signalement d'un message, d'un compte ou d'un espace, avec le message transmis par celui qui signale.
- File de l'opérateur, blocage d'un compte, fermeture d'un espace.

## Terminé quand

- Un signalement arrive dans la file de l'opérateur, qui peut bloquer un compte ou fermer un espace.
- L'opérateur ne voit que ce qui lui a été transmis.
