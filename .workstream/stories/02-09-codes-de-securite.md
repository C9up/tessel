# Codes de sécurité

Deux personnes vérifient qu'elles se parlent bien, par un code ou un QR.

## Critères d'acceptation

- Code numérique et QR dérivés des identités de compte des deux personnes ; identiques des deux côtés.
- Le code change si l'identité de compte change ; l'interlocuteur vérifié est alors averti.
- Un nouvel appareil d'un contact vérifié est signalé.
