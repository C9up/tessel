# Ajouter un bot à un salon

Seul un admin ajoute un bot, salon par salon, avec un rôle qui borne ce qu'il peut faire.

## Critères d'acceptation

- Un admin ajoute un bot à un salon précis ; un membre ordinaire ne le peut pas.
- Le bot reçoit un rôle (epic 10) : poster, épingler, modérer… ; ce qu'il tente au-delà est refusé par les autres membres.
- Retirer le bot l'exclut du groupe MLS : il ne lit plus rien ensuite.
