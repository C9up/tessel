# Signaler un message, un compte ou un espace

Celui qui signale transmet lui-même le message en cause.

## Critères d'acceptation

- Signalement depuis le client, avec le ou les messages choisis transmis en clair à l'opérateur.
- L'authenticité du message signalé est vérifiable (signature MLS de l'expéditeur) ; sinon le signalement l'indique.
- Limitation contre les signalements abusifs.
