# File de l'opérateur

Un écran d'administration pour traiter les signalements.

## Critères d'acceptation

- Liste des signalements, état, décision, journal des actions (écran d'admin, `station` si adapté).
- Accès réservé à l'opérateur, par `warden`.
- Les messages signalés sont effacés après la décision et un délai documenté.
