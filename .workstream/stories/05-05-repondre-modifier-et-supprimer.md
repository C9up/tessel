# Répondre, modifier et supprimer

Répondre à un message précis, corriger une faute, retirer un message pour tous.

## Critères d'acceptation

- Réponse citant un message.
- Modification avec mention « modifié » ; suppression pour tous dans une durée limite.
- Ce sont des messages de contrôle chiffrés : le serveur ne sait pas qu'un message a été modifié.
