# Comptes bot visibles de tous

Un type de compte « bot », vérifiable par chaque membre et signalé partout dans l'interface.

## Critères d'acceptation

- Le certificat d'appareil d'un bot le dit bot ; le cœur refuse qu'un compte bot se présente comme un compte ordinaire.
- Badge sur chaque message d'un bot ; chaque salon liste ses bots, qui les a ajoutés et qui les héberge (auteur ou opérateur).
- Un membre est prévenu quand un bot entre dans un salon où il est.
