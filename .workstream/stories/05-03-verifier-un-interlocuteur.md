# Vérifier un interlocuteur

Comparer les codes de sécurité et marquer un contact comme vérifié.

## Critères d'acceptation

- Écran du code de sécurité ; scan du QR de l'autre pour vérifier en un geste.
- État « vérifié » visible dans la conversation.
- Alerte claire si le code d'un contact vérifié change.
