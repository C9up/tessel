# Liaisons natives pour Expo

Le cœur est un module natif d'Expo, avec la même API que sur le web.

## Critères d'acceptation

- Liaisons par `uniffi-bindgen-react-native`, emballées en module Expo.
- Build Android `arm64` et `x86_64` ; testé sur émulateur.
- Même API que les liaisons WASM (mêmes noms, mêmes types).
